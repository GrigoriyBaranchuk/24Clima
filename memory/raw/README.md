# raw/ — неизменяемые источники

Сюда кладутся внешние материалы, которых нет в репозитории и которые
нужно сохранить дословно. Агент их **читает, но никогда не редактирует
и не удаляет**.

## Что класть

| Подпапка | Что |
|---|---|
| `gsc/` | выгрузки Search Console (CSV/JSON), скриншоты проблем |
| `dataforseo/` | сырые ответы SERP/rankings/backlinks |
| `serp/` | сохранённые страницы конкурентов, разборы выдачи |
| `reviews/` | ревью codex / seo-reviewer, если важна дословность |
| `clients/` | письма, брифы, требования от клиентов и администраторов PH |
| `google/` | переписка с поддержкой Google, документация по инцидентам |

Имя файла: `YYYY-MM-DD-краткий-слаг.<ext>`.

## Что НЕ класть

Файлы репозитория (`src/**`, `docs/**`, `PROJECT_MEMORY.md`, `DESIGN.md`) —
они уже под гитом. Страница в `wiki/sources/` ссылается на них путём,
копия не нужна.

Секреты, ключи, `.env`-значения, персональные данные клиентов сверх
необходимого. Вики лежит в публично клонируемом репозитории.

## После добавления файла

Попроси агента заингестить: он прочитает источник, заведёт
`wiki/sources/<слаг>.md`, обновит затронутые страницы и `wiki/log.md`.
Правила — в `memory/CLAUDE.md`.
