# Панама — закупки (PanamaCompra / Ley 22), фианзы, формат котизации, стек credentials (2026-08-23)

Субагент «Panama procurement and credentials». FACT — прочитано в источнике (включая первичный текст Ley 22 из Gaceta 29107-A); ESTIMATE — отраслевая типовая оценка.

## 1. Госзакупки — Ley 22 de 2006 (Texto Único, Ley 153/2020)
Источник: enterector.gob.pa/wp-content/uploads/2021/07/Ley-22-de-27-de-junio-de-2006-ordenado-por-Ley-153-de-2020.pdf
| Правило | Статья | Статус |
|---|---|---|
| Registro de Proponentes обязателен для всех, включая **субподрядчиков**; онлайн | Art. 174 | FACT |
| Contratación menor ≤ B/.50 000: без fianza de propuesta; ≤ B/.10 000 — procedimiento por cotizaciones | Art. 57 | FACT |
| **MIPYME-преференция:** побеждает при цене ≤ 5% выше лучшей не-MIPYME (нужен флаг MIPYME в реестре, AMPYME обновляет ежегодно) | Art. 57 | FACT |
| Licitación pública > B/.50 000 (цена решает); mejor valor > B/.500 000 | Art. 58–59 | FACT |
| Orden de compra вместо контракта ≤ B/.250 000 | Art. 105 | FACT |
| Сроки публикации obras: 10–50k ≥3 дн; 50–300k ≥5; 300k–3M ≥10; 3–7M ≥15; >7M ≥30. Bienes/servicios: >175k ≥30 | Art. 48 | FACT |
| Reunión previa/homologación обязательна > B/.175 000 | ~Art. 50 | FACT |
| Утверждение: ≤300k — ведомство; 300k–3M — CENA; >3M — Consejo de Gabinete | Art. 2 | FACT |

**Fianzas (Arts. 119–129, FACT):** propuesta **10%** только при референсной цене > B/.500 000; cumplimiento при актах > B/.50 000, срок — исполнение + 1 год (bienes) / **3 года** (строительные дефекты); pago anticipado ≥100% аванса; **аванс государства ≤ 20%** контракта (>B/.3M через fideicomiso MEF); impugnación 10%/15%; llave en mano — cumplimiento до 100%; принимаются фианзы страховщиков/банков из списка Superintendencia.
**Проценты cumplimiento (Contraloría Decreto 21-LEG, 28.03.2018):** obras **min 50%** контракта (>B/.2M: 15–45%); bienes/servicios **min 10%**.
**Оплата госработ (Art. 100, 109):** ежемесячные cuentas de avance; удержание по pliego (типично **10%**, EST); возврат в течение 60 дней после окончательной сдачи; просрочка государства → intereses moratorios (Art. 1072-A Código Fiscal); реальные задержки — месяцы (EST).
Примеры HVAC-тендеров: Universidad de Panamá 2008 — «sistema de ducto 6 salidas + A/A autocontenido 5 TR», contratación menor, оплата contado, 30 дней, обязательный site visit, без ITBMS (UP освобождён); UNDP для INADEH 11/2024 — сплиты для albergues (через Quantum, не PanamaCompra). PanamaCompra давал HTTP 500. EST: основная масса HVAC-актов — contratación menor ≤50k и лицитации 50–500k (MINSA, CSS, MEDUCA, университеты, муниципии).

## 2. Частные закупки
- Формат госзапроса де-факто шаблон и для частных: renglón / cantidad / unidad / descripción / P.U. / total + término de entrega, forma de pago, garantía, marca/modelo/país per line (FACT).
- Типично **3–5 приглашённых подрядчиков** на специальность; котизации принимает ingeniero residente / gerente de proyecto (часто через ГК) (EST).
- **Ingeniero residente — регулируемая роль** (JTIA Res. 947-2011); компания письменно уведомляет JTIA о найме/смене (FACT).
- Референсы удельных цен: **Contraloría «Base de Datos de Costos Directos de Obras»** FY 2025-26 по регионам, бесплатный PDF — contraloria.gob.pa/wp-content/uploads/2025/07/P0-BASE-DE-DATOS-DE-COSTO-DIRECTO.pdf; CYPE Generador de precios Panamá (>6 500 unidades de obra) (FACT).

## 3. Что содержит панамская cotización
| Элемент | Практика | Статус |
|---|---|---|
| Шапка | Proponente, RUC + DV, № Aviso de Operación, fecha | FACT |
| Тело | partidas/renglones: cantidad, unidad, P.U., total; marca/modelo/garantía per line | FACT |
| **ITBMS 7%** отдельной строкой (DE 84/2005); госуниверситеты и ряд ведомств освобождены — писать «exonerado» | FACT |
| **Удержание ITBMS:** крупные покупатели (закупки ≥ B/.3M/год) и госорганы удерживают **50% ITBMS** (= 3.5% счёта) и перечисляют сами (DE 173/2021, форма 4331) | FACT |
| Validez 30–60 дней | EST |
| Forma de pago: гос. мелкие — contado; частные — anticipo 30–50% + saldo за оборудование; obras — cuentas mensuales с 10% retención | EST |
| Ориентиры труда: базовый монтаж сплита Rodelag B/.65, Frío Panamá B/.140 | FACT |

## 4. Фианзы — кто выдаёт и почём
Internacional de Seguros (propuesta/cumplimiento/pago/anticipo; требует pacto social, cert. Registro Público, **2 года аудированной отчётности или деклараций**, банковские/коммерческие референсы, CV компании, список проектов); MAPFRE (378-9898); ASSA (форма PDF); брокер Panamerican Network (cert. ≤3 мес, 2+2 референса, 2 года FS; при недостаточной capacidad — co-signer/залог; премия полностью при выдаче).
**Стоимость (EST): 1–3% в год от суммы фианзы**; пример: obra B/.100k → cumplimiento 50% = B/.50k → ~B/.500–1 500/год. Новой/иностранной компании без 2 лет отчётности — contragarantía (депозит/CD) (EST).
