## Суть

Проектируемое новое направление 24clima: вентиляция кровли и
подкрышного пространства + вентилируемые фасады с солнечных сторон, чтобы
снизить тепловую нагрузку на помещения. Технологию приносит владелец
[TropiClima](../entities/tropiclima.md). Статус на 2026-08-17 —
**решение о вложениях не принято**, сделана аналитика рынка.

Итоговый отчёт: `https://claude.ai/code/artifact/6078d9e9-8515-47c7-9255-4d90abb49de6`.

## Решения владельца (сессия 2026-08-15/17)

| Вопрос | Решение |
|---|---|
| Кто выполняет работы | **24clima своими силами**; партнёр даёт технологию, расчёты, обучение |
| Сегмент | **Коммерция и промышленность (B2B)** — основа; застройщики и архитекторы — дополнение |
| Канал | Связей под услугу **нет**, B2B-доступ строить с нуля |
| Доказательная база | **Нет** ни объектов, ни замеров |
| Инженерный ресурс | Инженер **есть**, измерительного оборудования нет |
| Позиционирование | **Синергия с HVAC**: «кондиционер работает меньше», НЕ замена |
| Горизонт | Сначала аналитика, потом решение о вложениях |

Позиционирование «синергия» выбрано осознанно и решает три задачи сразу:
не бьёт по выручке от кондиционеров, даёт вход к клиенту через понятный
ему продукт, и снижает юридический риск по Ley 69 (продаётся инженерное
улучшение системы, а не энергоуслуга) —
см. [право](panama-advertising-law.md).

## Что показал рынок

- **Поискового спроса на услугу нет.** `ventilación de techo` 10/мес,
  `fachada ventilada` 10, `ventilación de ático` / `fachada ventilada
  panamá` / `aislamiento térmico panamá` / `turbina eólica de techo` —
  **0**. Английские запросы для экспатов — тоже 0–10
  [DataForSEO, 2026-08-15].
- **Тема экономии энергии мала:** 291 фраза и 3 560 показов суммарно, но
  280 из них по 10 показов (шум). Реальный размер темы — 250–350
  запросов/мес на всю страну: `ahorrar energía` 140, `ahorro de energía`
  70, `ahorro energético` 30.
- **Спрос есть рядом:** `ensa panamá` 18 100 и `naturgy panamá` 9 900
  (боль про счёт, но навигационная), `paneles solares` 880,
  `aire acondicionado inverter` 590, `aislante térmico` 320,
  `aislante térmico para techo` 260, `instalación de aire acondicionado`
  210 при **CPC $1,75** — самый дорогой клик в нише.
- **Единственная дверь в тему, которую панамец открывает сам** —
  `aislante térmico para techo`. Заходить в контент нужно через неё.
- **Сезонность ×3–4:** пик март–май, провал ноябрь–январь.
  `aire acondicionado inverter` 320 (окт) → 1 300 (май);
  `aislante térmico para techo` 140 (дек) → 480 (апр–май).
  Окно продаж — **февраль–июнь**.

## Конкуренты и поставщики

- **Nimbus Fans Panamá** — уже продаёт турбинные экстракторы из
  нержавейки (SST-24, SST-12) с прямым указанием применения: «áticos,
  fábricas, naves industriales, bodegas, talleres», то есть ровно наш
  продукт для нашего сегмента. Но ни цен, ни расчёта, ни проектирования,
  ни монтажа — это поставщик железа.
- **CFM Technologies** — инженеры, жестяной цех, монтаж; ближе всех к
  полноценной услуге.
- **HOPSA** (15+ филиалов, промышленные вытяжки), **PEMCO** — поставщики.
- **Вентфасады**: Mamport, Deco Plastic, Tecnocober, Vizion, Fachadas
  Modernas — все продают **эстетику и материал** (Alucobond,
  фиброцемент), никто не продаёт теплотехнику.
- Выдача по `aislamiento térmico techo panamá` — чисто товарная (Do It
  Center, Novey, Tolsen, Carbone, Ecotec): продают рулон фольги.
- По `ventilación de techo panamá` выдача **пуста**. По
  `aire acondicionado consume mucha luz` — ни одного панамского сайта
  (Midea, Reddit, испанские сайты): контентная дыра.

**Вывод:** оборудование не может быть отличием — оно доступно всем.
Отличие — инженерный слой: расчёт, замер, подтверждённый результат.

## Экономика

Якорные цены по Панаме (справочник CYPE, 2026-08):

| Позиция | Цена | Состав |
|---|---|---|
| Вентфасад, камень + минвата | **$211,75 / м²** | камень $100,31 · подконструкция $78,42 · минвата $8,22 · **работа $10,54** |
| Эоловый экстрактор 500 мм (гибрид, EC-мотор) | **$1 797 / шт** | материал $1 749 · работа $12,86 |
| Ставка монтажника | $20,58 / ч | помощник $12,84 / ч |

Характер бизнеса: в вентфасаде **работа — всего 5 % стоимости**. Это
перепродажа материала с монтажом, а не продажа труда; маржа
закладывается в поставку и в инженерию.

Модель для склада 1 000 м² (доля кондиционирования 40 %, снижение
8–15 % — **гипотеза, не замер**): при счёте $1 500/мес экономия
$576–1 080/год, при $3 000 — $1 152–2 160, при $6 000 — $2 304–4 320.
Отсюда правило отбора: **объект со счётом ниже ~$1 500/мес не брать**.

## Ограничения / чего не хватает

- Цена **пассивной** турбины SST-24 неизвестна: $1 797 из CYPE — это
  моторизованный гибрид, другой продукт. Берётся звонком поставщику.
- Доля кондиционирования в счёте конкретного объекта — только замером
  (для PH-башен в вики есть 60–80 %, для складов цифры нет).
- Процент снижения расхода 8–15 % ничем не подтверждён — это и должен
  закрыть пилот.
- Применяется ли требование аккредитации по Ley 69 к нашей модели —
  открыто, вопрос к юристу/SPIA.
- Условия партнёрства с владельцем TropiClima не обсуждались.

## Предложенный план (не утверждён)

1. **Сентябрь:** запросить прайс на турбины (Nimbus Fans, CFM, HOPSA);
   купить комплект замеров — тепловизор, логгеры температуры/влажности,
   токовые клещи.
2. **Октябрь–ноябрь:** один измеренный объект (свой или дружеский склад с
   металлической кровлей): месяц базового периода → монтаж → месяц после,
   с фиксацией погоды и режима.
3. **Декабрь–январь:** прайс, типовой расчёт окупаемости, презентация;
   консультация панамского юриста по Ley 69.
4. **Февраль–июнь:** продажи на пике сезона — через существующий контекст
   HVAC, прямые продажи по складам, контент под `aislante térmico para techo`.
