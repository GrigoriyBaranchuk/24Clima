# Портативные кондиционеры — продажа, аренда, подменные юниты

## Суть

Кандидат-направление для быстрого выхода магазина на оборот $10k/мес
(идея владельца, сессия 2026-08-26): продавать портативные (напольные)
кондиционеры, сдавать их в аренду и оставлять клиентам как подменные,
если ремонт кондиционера затягивается («no te dejamos en el calor»).
Статус: разведка проведена, решения о запуске НЕ приняты.

## Спрос (факты, DataForSEO 2026-08-26)

- «aire acondicionado portatil»: 2 900/мес avg по Панаме, **+132% г/г**;
  сезон: пик апрель–июль (4 400–6 600), низ октябрь–ноябрь (~1 300).
  С хвостом — 5 000–8 000 поисков/мес в сезон, интент транзакционный.
- Реклама не выкуплена: CPC $0.17–0.36, competition LOW — дешёвый Google Ads.
- **Аренда через поиск не продаётся** (~10 запросов/мес) — канал только
  офлайн: клиенты ремонта, WhatsApp, B2B (офисы, рестораны, event), см.
  [сегменты клиентов](hvac-customer-segments.md).
- Конкурентов по аренде портативников в Панаме нет; по продаже — весь
  ритейл (Novey, Do It Center, Panafoto, Multimax, Rodelag, Aiwa, Titan)
  и friopanama.com (HVAC-магазин в топ-5 SERP — прецедент, что такой сайт
  может ранжироваться).

## Экономика (ориентиры, не котировки)

- Розница Панамы: $200–270 за 12k BTU (Hisense доминирует), $320 за 14k.
- Налоги при импорте: **HS 8415.82 → DAI 15% + ITBMS 7% ≈ +23% от CIF**
  (арансель ANA; у 8415.81 «с реверсивным циклом» DAI 10%).
- FOB Китай: 9k BTU ~$130–160 (100+ шт), 12k ~$170–220; контейнер 40' —
  ~200–450 юнитов, к нижней границе. Landed прямого импорта ~$185–200 →
  маржа $70–90/шт. Закупка через ZLC: landed ~$240+ → маржа с продажи
  тонкая (~$25), но нормальная для аренды.
- Аренда: при ставке ~$150–200/мес юнит окупается <2 мес (прикидка,
  локального рынка аренды нет). Б/у уходят на Encuentra24 по $150–200 —
  вторичный канал для флота.
- Путь к $10k/мес — микс: ~20 продаж + флот аренды 10–15 шт + B2B/подмена.
  Только продажами против сетей — нереалистично (37 шт/мес).

## Каналы закупки

1. **ZLC (быстрый старт, без резидентства):** оптовики IMEXCA
   (+507 441-6100, WhatsApp 6379-8776), Gera Enterprises (+507 431-1322),
   Panafoto B2B (b2b.panafoto.com). Процесс: factura → продавец делает
   DMCE de salida → corredor de aduanas ($60–80) → DAI+ITBMS → доставка в
   PC за 24 ч. Тестовая партия 10–20 шт ≈ $3–5 тыс. Резидентство ZLC не
   нужно (фикс-косты ~$6–8 тыс./год, льготы только на реэкспорт).
2. **Прямой контейнер из Китая (маржа, к сезону):** ODM — JHS (Дунгуань),
   Midea/Gree/TCL, фошаньские. Производство 25–40 дн + море 35–45 дн:
   заказ в окт–ноя приходит к янв–фев, к пику сезона.
3. **Русклимат — слабый вариант:** свой завод в Чжуншане мал, мобильники —
   OEM тех же Gree/Midea/TCL, 60Гц-версий нет, экспорта вне СНГ нет,
   платёж в юрлицо РФ — комплаенс-риск. Если использовать — только через
   их китайское/гонконгское юрлицо и с кастомной 60Гц-партией.

## Грабли / ограничения

- **Напряжение: Панама 120В/60Гц.** Российские/СНГ-версии (220В/50Гц) не
  подходят — это другой компрессор и мотор, не переключатель. Заказывать
  явно 115В/60Гц (заводы делают серийно для США), желательно ETL/UL.
- Пошлина считается по коду: 8415.82 = 15%; у товара из стран с ТПС
  (США и др.) ставка может быть ниже — проверять происхождение.
- Стартовать сейчас (авг–сен) = входить в низкий сезон; использовать
  окно для теста через ZLC и подготовки контейнера к марту.
- Не проверено публично (уточнить у брокера): порог B/.500 Carta Paquete,
  тарифы брокеров после Res. 352/2024, цена палеты Колон→PC.
